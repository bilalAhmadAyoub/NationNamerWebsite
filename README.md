# Nation Namer

Nation Namer is an educational geography game that helps players learn the locations of different countries on a map. The game orders countries based on their population size, making it easier at first with more recognizable countries like China, India, and the United States, and progressively harder with smaller countries like Nauru, Tuvalu, and Montserrat. However, the order still retains an element of randomness to keep the game engaging.

## How to Play

1. Visit the website: [Nation Namer](https://nationnamer.netlify.app/index.html)
2. Follow the on-screen instructions to start the game.
3. Identify the countries on the map as they appear.
